System architecture

Airflow publishes approved models through the authenticated API bridge. Kubeflow runs the same ETL and training code and records a separate artifact lineage.

Forecast and validation

The ridge autoregression uses lagged log returns, moving-average ratios, and seven-day volatility. The model predicts one daily close at a time and feeds that prediction into the next step. The latest seven closes form the chronological holdout. The baseline repeats the last pre-holdout close.

A candidate passes when MAPE is at most 25% and RMSE is at most the larger of 1.5 times baseline RMSE and 0.5% of the last pre-holdout close. The approved model is then refit on all available observations.
